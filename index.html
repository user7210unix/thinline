filters
syntax

Use regular expressions, one per line. Lines starting with # are ignored. Example: /weeaboo/i filters posts containing "weeaboo", case-insensitive. MD5 and Unique ID filtering use exact string matching, not regular expressions.

  • Separate settings for a rule with semicolons.
  • boards:a,jp; — scope to boards, comma-separated. Global if omitted. Use sfw / nsfw for worksafe status. Prefix a site with 4: and an asterisk * means all boards, e.g. boards:4:*;
  • exclude:vg,v; — same syntax, excludes boards from the filter.
  • op:only; or op:no; — OPs (with thread) only, or replies only.
  • file:only; or file:no; — only posts with / without a file.
  • stub:yes; or stub:no; — force a clickable stub instead of the global setting.
  • highlight; or highlight:classname; — highlight instead of hiding.
  • top:yes; — pin highlighted OP threads to the top of the catalog.
  • notify; — show a desktop notification instead of hiding.
  • type:name,comment; — default is subject,name,filename,comment. Fields: postID, name, uniqueID, tripcode, capcode, pass, email, subject, comment, flag, filename, dimensions, filesize, MD5. Join fields with + to test them together, e.g. type:filename+filesize;
